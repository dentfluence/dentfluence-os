The defect you found

The write path was correct. The read path inferred clinical truth from PRE state: the plan card computed "presented" from "does this plan have any Opportunity row" — any status, not just quoted. So the pipeline manufactured clinical truth, showed commercial language on a clinical card, and hid the action.
  • Live proof, patient 3869: a plan sat is_accepted: true with presented_at: NULL — accepted without ever being presented, because Accept was reachable before presentation.
  • My own formatPlan() carried the same inference labelled "compatibility fallback". Same violation, with a reassuring comment on it. Removed.
  • Three real presentation paths (case journey sent, patient opens journey, patient opens smart presentation) only moved the Opportunity and never recorded the clinical fact. All now go through the one canonical service.

Expected consequences — not defects

  • Historical plans read "Not Presented" even where an estimate genuinely went out. We refuse to convert a sales-card position into a clinical date. Staff record it once.
  • Accepted-but-never-presented plans keep a NULL presentation date. They show as Accepted with no presentation date. No date was invented.
  • Commercial stage disappeared from the clinical card — it lives on Relationship → Journeys, which is where pipeline belongs.

Open debt (declared, not hidden)

  • Two controllers still create opportunities directly (decline / callback). Commercial-only transitions — they never touch clinical truth — but "one writer" is not yet literally true of the board.
